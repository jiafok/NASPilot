## 2. Web 管理端（NASPilot 内）

路径：`/english`，菜单「英语学习」。

### 2.1 页面结构（单页 + 三个视图）

```
┌──────────────────────────────────────────────┐
│ 英语学习                    [扫描媒体库] [统计] │
├──────────────┬───────────────────────────────┤
│ 筛选侧栏      │  课程网格 / 课程详情 / 播放器    │
│ · 频道        │                               │
│ · 分类        │                               │
│ · 难度        │                               │
│ · 仅收藏      │                               │
└──────────────┴───────────────────────────────┘
```

### 2.2 视图 1：课程库（默认）

- 筛选栏（互相独立，可组合）：频道 / 难度（CEFR）/ 话题 / 技能 / 形式 / 收藏
- 课程卡片显示：难度徽标（A1..C1，附解释悬浮提示）、前两个话题、形式
- 顶部：库根目录状态条（复用媒体库时显示 `<DATA_DIR>/media`；是否存在、课程/课时/字幕数量）
- 课程卡片：封面（无封面则渐变占位 + 首字母）、标题、频道、课时数、总时长、
  难度徽标、收藏星标
- 空状态：提示「媒体库还没有可用的音视频，或点扫描」，附目录规范链接

### 2.3 视图 2：课程详情

- 头部：大封面 + 标题 + 频道/分类/难度 + 描述 + 收藏按钮
- 课时列表：序号、标题、时长、是否有字幕、进度条、完成勾选
- 右侧（宽屏）：课程生词表（按频率），可点「重新提取」

### 2.4 视图 3：播放器

- 左：`<video>` 或 `<audio>`，源 `GET /api/media/{lessonId}`
- 右：字幕面板，句子列表可点击 seek，当前句高亮（随 timeupdate 自动滚动）
- 底部：上一课 / 下一课、标记完成
- 工具条：`AI 总结`、`AI 讲解当前句`、`提取生词`
- 书签：在当前句上加标记，列表可跳回

### 2.5 交互细节

| 交互 | 行为 |
| --- | --- |
| 点字幕句 | 播放器 `currentTime = start/1000`，自动滚动到该句 |
| 播放中 | 每 10 秒上报一次 `POST /api/english/progress` |
| 完成判定 | 播放到 ≥95% 或手动勾选 |
| AI 未配置 | 按钮置灰 + Tooltip「请先在系统设置 → AI 配置 Key」 |
| 扫描中 | 按钮 loading，完成后 toast 显示新增/更新/缺失数量 |

### 2.6 视觉规范

| 项 | 值 |
| --- | --- |
| 主色 | 沿用 NASPilot `#667eea` |
| 卡片圆角 | 12px |
| 封面比例 | 16:9（视频）/ 1:1（音频播客） |
| 字号层级 | 标题 20 / 卡片标题 15 / 正文 13 / 辅助 12 |
| 暗色 | 跟随 antd `defaultAlgorithm`，不额外自定义 |

## 3. EnglishFlow 移动端契约（Flutter，仅定义）

### 3.1 固定底部导航（不可增删）

```
首页   发现   学习   AI老师   我的
```

**禁止**出现：下载 / 媒体库 / 文件 / 目录 / 资源管理。

### 3.2 每页数据来源

| 页 | 接口 |
| --- | --- |
| 首页 | `GET /api/english/home` |
| 发现 | `GET /api/english/courses`（分页 + 筛选） |
| 学习 | `GET /api/english/home` 的 `continue_learning` + `progress` |
| AI 老师 | `POST /api/english/ai/chat` |
| 我的 | 收藏 / 统计（由 home.stats + courses?favorite=1 组合） |

### 3.3 播放器（Flutter 侧）

- 媒体：`GET /api/media/{lessonId}`（支持 Range，可拖动）
- 字幕：`GET /api/english/transcript/{lessonId}`（对话材料带 `spk` 字段，UI 在换人处显示「说话人 A / B」并留出间距，同一个人的连续台词成组）
- 进度：`POST /api/english/progress`，退出前必报一次
- 缓存：仅缓存媒体到本地，**不缓存元数据**（保证服务端为准）

### 3.4 文案原则

用户感知必须是「英语学习产品」，不得出现：
NAS / 磁盘 / 目录 / volume / 容器 / 下载任务 / SMB。
